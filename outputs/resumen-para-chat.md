# Resumen breve para planificación

NexoEventos conserva React/TypeScript, FastAPI y PostgreSQL con sesiones, roles, reservas transaccionales/idempotentes y QR de un solo uso. Se prepararon Nginx, systemd, cookies Secure/CSRF, rate limit, manejo de secretos, restore aislado, Terraform AWS V1 y matriz EV01–EV10. Pasaron 16 pruebas backend, 1 frontend, build y `terraform validate` en AWS/Azure/GCP. AWS no se inició y no hubo `plan/apply`; costo V1 estimado sin créditos: USD 0.404 por 8 h y USD 36.903/mes. Azure está activo y sin recursos; solo permite cinco regiones y Compute/Network/Storage están no registrados. Saldo/vencimiento Azure esperan selección de cuenta/MFA. Faltan dominio/certificado, inventario/plan AWS y evidencias cloud reales; no está listo para producción.
