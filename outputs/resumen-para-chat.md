# Resumen breve para planificación

NexoEventos está preparado para Amazon Linux 2023 con Nginx, FastAPI/systemd sin privilegios, Python 3.11 aislado y dependencias fijadas. Terraform exige cuenta esperada, estado separado por cuenta, perfil IAM explícito y snapshot final; `fmt`/`validate` pasan. Se resolvió `InvalidClientTokenId`: no había variables antiguas reemplazando el perfil, sino un session token truncado por la representación accesible. Con los tres componentes de la misma sesión en un entorno aislado, STS funcionó y el plan vigente dio 30 altas, 0 cambios y 0 eliminaciones, sin advertencias. No se ejecutó `apply` ni `destroy`.

El costo corregido es USD 36.465 por 720 horas/30 días continuos. En el escenario más temprano del 2 de octubre 15:00 al 26 de noviembre 23:59, con 37 horas activas: subtotal USD 10.719 + margen USD 3.000 = techo USD 13.719. No es costo real porque aún no hay recursos NexoEventos; tras `apply` se usarán timestamps reales. Se revisará consumo al observar USD 30 y USD 40; no son límites automáticos.

Secretos: carga sin eco, archivos root-only, identidades RDS maestra/migración/aplicación separadas; el permiso para leer el secreto maestro se probará en la EC2 real. DuckDNS + Let's Encrypt es la decisión y `nexoeventos-demo.duckdns.org` está confirmado. DNS/HTTPS siguen pendientes. El token observado durante la revisión debe regenerarse personalmente antes de introducirlo por prompt sin eco. La administración EC2 prevista es Session Manager con `LabInstanceProfile`; solo está documentada, no probada sobre una instancia. Restore local, snapshot final, backup cifrado externo y migración entre cuentas están documentados.
