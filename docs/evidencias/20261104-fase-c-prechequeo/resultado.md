Se contrastó contra `aws rds describe-certificates` (API autenticado, host y canal distintos de `truststore`): la huella SHA-1 devuelta para cada CA (`rds-ca-rsa2048-g1`, `rsa4096-g1`, `ecc384-g1`) **coincide** con la del certificado correspondiente del paquete regional de us-east-1.
